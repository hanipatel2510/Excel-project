
# 📊 PR. 1 Fundamental Booster – Excel Project

## 📌 Project Overview
This project demonstrates proficiency in essential to intermediate Microsoft Excel functions and analytical techniques. Using three real-world business scenarios—**Student Grades**, **Sales Performance**, and **Employee Records**—the project covers advanced formulas, dynamic lookups, conditional logic, text manipulations, date calculations, and dynamic array filtering.

---

## 📑 Worksheets Structure

* 🎓 **Student Grade** – Student marks, total and average calculations, nested IF grade classification, logical checks (AND/OR), text extraction (`LEFT`, `FIND`, `UPPER`), dynamic array filtering (`FILTER`), and summary analytics.
* 📈 **Sales Data** – Product transaction records, discount tiers (Nested IF & OR), mathematical rounding (`CEILING`, `FLOOR`), dynamic multi-criteria summaries (`SUMIFS`), and lookup mechanisms (`VLOOKUP`, `INDEX-MATCH`, `XLOOKUP`, `XMATCH`, `OFFSET`).
* 👥 **Employee Data** – Employee profiles, salary metrics, date difference/tenure calculations (`DATEDIF`), dynamic references (`INDIRECT`), case formatting (`LOWER`), and salary search pipelines.
* 📋 **Project Instructions** – Comprehensive checklist of project objectives and core learning outcomes.

---

## 🛠️ Key Excel Functions & Concepts Covered

* 🧮 **Mathematical & Statistical**: `SUM`, `AVERAGE`, `COUNTIF`, `COUNTIFS`, `SUMIFS`, `AVERAGEIF`, `ROUND`, `CEILING`, `FLOOR`, `MAX`, `MIN`
* 🔍 **Lookup & Reference**: `VLOOKUP`, `XLOOKUP`, `INDEX`, `MATCH`, `XMATCH`, `OFFSET`, `INDIRECT`
* ⚡ **Logical Functions**: `IF`, Nested `IF`, `AND`, `OR`
* ✂️ **Text Manipulation**: `LEFT`, `FIND`, `UPPER`, `LOWER`
* 📅 **Date & Time**: `DATEDIF`, `TODAY`
* 🎯 **Dynamic Arrays**: `FILTER`
